# Product truth lives in `1n1-studio`

This repository is public. The 1n1 studio's product brief, its amendments and its Issues carry the
owner's source material and private detail, so they live in the private repository:

- brief: `1n1-studio/docs/product/brief.md`
- amendments: `1n1-studio/docs/product/amendments/`
- Issues: <https://github.com/1n1-apps/1n1-studio/issues>

A ticket for this site is an Issue there. Its plan and ADRs live here, beside the code, and its PR
closes the Issue across repositories (`Closes 1n1-apps/1n1-studio#<n>`). Read the brief and the newest
amendments before changing a page.
