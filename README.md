# 1n1 site

Source for the 1n1 website, served by GitHub Pages. Everything in this repository is public.

Brand source, copy drafts and setup records live in the private `1n1-apps/1n1-studio` repository. Images
this site serves (favicons, share cards) are generated there and copied in. Agents working here follow
[`AGENTS.md`](AGENTS.md).

Hosting, the custom domain and the build are set up by
[E2-A1](https://github.com/1n1-apps/1n1-studio/issues/6); the site itself is
[E2-F1](https://github.com/1n1-apps/1n1-studio/issues/7).
